# Administrative boundaries

`{Country}-1.geojson` is the first administrative level (Kenya counties,
Rwanda provinces, Uganda regions); `{Country}-2.geojson` is the second
(Kenya sub-counties, Rwanda districts, Uganda districts).

Source: [geoBoundaries](https://www.geoboundaries.org) gbOpen, release
`9469f09`, simplified geometries. Reduced to the `shapeName` property, with
coordinates rounded to 4 decimals and consecutive duplicate points removed.
